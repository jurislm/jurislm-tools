## 1. 模型定位

H3 是統一多模態影片模型，可在同一脈絡中理解文字、圖片、影片與音訊。它的核心不是單純「文字轉影片」，而是把素材分工、鏡頭、動作、剪輯、聲音與編輯要求一起轉成短影片。

三個主要能力：

1. **原生多模態理解與生成**：混合參考人物、物件、場景、動作、鏡頭、節奏、音色與聲音。
2. **精準多模態編輯與控制**：替換、增加或移除角色／物件，換場景、重打光、加特效、改對白、聲音或音色，同時保留未指定的部分。
3. **商業多場景製作**：品牌、影視、社群、產品、UI、工業、動畫與互動內容。

## 2. 輸出規格

| 項目 | 官方手冊整理 |
| --- | --- |
| 單次時長 | 4–15 秒 |
| 幀率 | 24 FPS |
| 原生音訊 | 影片原生包含立體聲音訊 |
| 提示詞 | 最多 7000 字元 |
| 語言 | 支援多語提示與輸出；精準 TTS 覆蓋 11 種語言，另有 40+ 語言探索能力 |

### 畫幅

- 文字生影片：21:9、16:9、4:3、1:1、3:4、9:16。
- 首尾幀模式：跟隨輸入圖片比例。
- 全能參考：支援上述比例與 Auto。

### 解析度

- **768p 路徑**：在常見橫直畫幅範圍以短邊 768 為基準；較寬或較特殊畫幅約維持 100 萬像素。官方示例 21:9 約為 1536×672。768p 結果可再升級到 1440p。
- **1440p／2K 路徑**：官方高品質建議。常見畫幅以短邊 1440 為基準；特殊畫幅約維持 370 萬像素。官方示例 21:9 約為 2976×1248。
- MiniMax Design 目前影片模型選單把 H3 標示為 `2K 4-15s`；仍以實際任務卡與結果節點為準。

## 3. 輸入模式與限制

### 3.1 文字生影片

- 不提供媒體素材。
- 描述人物／物件外觀、場景、動作、鏡頭、風格、聲音與限制。
- 多鏡頭可採「建立場景的廣角 → 行動中景 → 細節特寫」。

### 3.2 首尾幀／圖片生影片

- 可提供 0、1 或 2 張圖片。
- 1 張圖必須明確指定為首幀或尾幀。
- 2 張圖分別指定首幀與尾幀，由 H3 補全中間運動、光線與聲音。
- H3 不會因為有一張圖就自動加入剪接；需要換鏡時要明寫。

圖片條件：

- 尺寸 256–5760 像素。
- 長寬比介於 5:2 與 2:5。

### 3.3 全能參考

| 素材 | 上限 | 個別條件 | 類別總長 |
| --- | --- | --- | --- |
| 圖片 | 9 張 | 256–5760 像素；比例 5:2–2:5 | 不適用 |
| 影片 | 3 段 | 每段 2–15 秒；尺寸與比例同上 | 最多 15 秒 |
| 音訊 | 3 段 | 每段 2–15 秒 | 最多 15 秒 |

- 圖片、影片與音訊混合總數最多 12 個。
- 音訊不能作為唯一輸入；至少要搭配圖片或影片。
- 沒有媒體時退回文字生影片。

## 4. 格式與檔案大小

| 類型 | 格式 | 單檔上限 |
| --- | --- | --- |
| 影片 | H.264/AVC、H.265/HEVC；內嵌音訊可為 AAC/MP3 | 50 MB |
| 圖片 | JPG、JPEG、PNG、WEBP、HEIC、HEIF | 30 MB |
| 音訊 | WAV、MP3 | 15 MB |

- API request body 64 MB 是 API-only 參考；官方對 API 使用建議以 URL 傳入素材。本 Plugin 不呼叫 API。桌面工作流可使用上表的格式與單檔上限驗證附件；動態可用性、模型、入口、費用與衝突限制仍必須以目前 UI 驗證。若 UI 顯示相衝突的限制，應停在 `VALIDATE`。

## 5. 素材角色

每個素材都要在提示詞中有明確工作。常見角色：

- 人物身份與臉部一致性。
- 服裝、產品或特定物件。
- 場景、背景、空間與光線。
- 首幀、尾幀或中間關鍵幀。
- 姿勢、動作、表演或情緒。
- 鏡頭運動、構圖與景別。
- 分鏡、剪輯節奏或影片編輯來源。
- 視覺風格、材質與色彩。
- 聲音直接重用、局部重用、音色或說話人參考。

在提示詞中使用介面顯示的素材編號，例如 `@图片1`、`@视频1`、`@音频1`，並緊接著寫它要控制什麼、哪些特徵必須保留。

素材「已上傳」不代表模型知道用途。角色沒有寫清楚時，先補角色，不送出。

## 6. 提示詞骨架

官方建議的核心公式：

`參考素材說明 + 核心創意 + 畫面過程描述`

### 6.1 參考素材說明

逐一寫：

- 素材編號。
- 角色：身份、動作、場景、風格、音色、首／尾幀等。
- 必須保留的具體特徵。
- 可以改變的部分。

需要複製歌詞或對白時，把確切文字也寫進提示詞；不能只說「沿用音訊內容」。

### 6.2 核心創意

至少包含：

- 主體。
- 地點。
- 事件。
- 類型或視覺風格。
- 必要的鏡頭或剪接語言。

抽象概念要翻譯成可見事件。例如不要只寫「充滿希望」，而是寫光線、表情、身體動作、場景變化與色彩如何讓觀眾看出希望。

### 6.3 畫面過程

依時間或鏡頭描述：

- 誰在什麼位置。
- 做了什麼可辨識動作。
- 鏡頭怎麼移動、何時剪接。
- 光線、材質、特效如何變化。
- 對白、環境聲、音效與音樂何時進出。
- 不可出現的內容。

### 6.4 官方提示詞章節對照

- **1.1 整體公式**：參考素材說明＋核心創意＋可見過程。
- **1.2 四個要素如何描述**：主體／場景／動作／鏡頭與聲音、限制要用可觀察語句。
- **1.3 鏡頭怎麼拆**：按鏡頭順序、時長、景別、相機運動與切點拆解。
- **1.4 三類模式生視頻，提示詞分別怎麼寫**：文字生影片、首／尾幀、全能參考各自列出輸入角色與限制。
- **1.5 容易踩的坑**：避免抽象形容、矛盾的「一鏡到底／多鏡」、沒有身份參考、台詞超出鏡頭時間，以及只關音訊不關嘴型。
- **特定風格與最佳方式**：把風格拆成光線、材質、色彩、鏡頭、節奏與負面限制；送出前用短而完整的結構化 prompt 讀回檢查。

## 7. 鏡頭與剪接

H3 具有基本鏡頭規劃能力，也能跟隨明確切點。提示詞仍要把可驗證的鏡頭條件寫出來。

### 鏡頭運動

- 推、拉、平移、搖鏡、跟拍、手持、升降、變焦等要指定方向與速度。
- 需要環繞感時，官方建議把它拆成可操作語言，例如「向左平移並向右搖鏡」，不要只寫抽象的「環繞鏡頭」。

### 剪接

- 可指定硬切、淡入淡出、節奏剪輯或快速剪輯。
- 在切點寫新景別與仍需保持一致的既有人物。
- 「一鏡到底」和多個 `Shot N` 是矛盾要求；一鏡到底應改成同一連續事件與鏡頭路徑。

### 對白跨鏡

- 每段對白長度要能放入該鏡頭時長；3 秒鏡頭不要塞入長句。
- 可指定 J-cut 或 L-cut，並寫明對白跨越哪些鏡頭。
- 標示畫面內說話者、畫外說話者與切換時機。

## 8. 聲音、音樂與沉默

H3 原生輸出包含聲音。提示詞要把聲音當作畫面流程的一部分，而不是最後才補一句。

### 音效

- 把音效寫在對應動作旁。
- 再依事件順序整理一次整體聲景，避免音效時間錯置。

### 音樂

- 寫清楚風格、樂器、速度、節拍與進出點。
- 需要事件同步時，可用「事件前無音樂 → 事件發生時進入 → 事件後完全停止」。
- 描述相對混音關係，例如「對白清楚在前、音樂較低」，不要假設百分比或 dB 能被精準執行。

### 不要額外音樂

同時使用：

- `non_diegetic_music: N/A`
- 明確寫「不要加入額外 BGM」。

### 不要說話或嘴型

實務上只寫「靜音」可能移除聲音卻保留嘴型。更可靠的組合：

- 正向狀態：保持沉默、嘴巴閉合、持續非說話動作。
- 負向限制：無對白、無旁白、無嘴型動作。
- 避免引發說話的引號、台詞字樣或口播語彙。
- 必要時選擇側面、背面或中遠景，降低嘴部顯著度。

## 9. 多模態組合模式

### 9.1 多素材聯合參考

把圖片、影片、音訊與文字放進同一脈絡，為每個檔案指定身份、動作、鏡頭、節奏、音色或風格角色；總數與單檔限制仍遵循第 3、4 節。

### 9.2 角色、動作與鏡頭參考

可分別用人物圖鎖身份、影片鎖動作／鏡頭、音訊鎖聲音；提示詞要說明只借用哪一部分，並列出必須保持與允許改變的特徵。

### 9.3 音色克隆與遷移

音訊參考只負責說話人音色；對白文字、語言、情緒、語速與音效要另外寫明。這不是 Music Generation、Music Cover 或獨立 TTS 的替代流程。

### 身份＋動作＋鏡頭

- 人物圖鎖身份與外觀。
- 影片鎖動作、表演或鏡頭。
- 提示詞說明要保留人物哪些特徵，以及只借用參考影片的哪一部分。

### 多張關鍵幀＋節奏參考

- 圖片分別標為關鍵幀與順序。
- 參考影片只提供剪輯節奏、鏡頭或音樂，不必複製角色。

### 選擇性風格替換

- 指定哪些角色或區域換風格。
- 明確要求其他部分保持原狀。

### 材質匹配轉場

- 說明前後物體共享的形狀、紋理或運動。
- 描述材質如何連續變形，避免只有「無縫轉場」的抽象要求。

### 音色遷移

- 音訊參考負責說話人音色。
- 對白文字、語言、情緒與語速另行明寫。
- 官方示例把音色克隆與遷移列為 H3 的獨立多模態能力；不要把音色參考誤當成完整歌詞、Music Generation 或 TTS 交付。每次使用都要明確指定來源音訊、說話文字、語言、情緒與保留／禁止項目。

### 語言與本地化

- H3 支援多語言提示詞與輸出；官方明列 TTS 可精準覆蓋中文、英語、日語、韓語、法語、德語、西班牙語等 11 種語言，並可探索阿拉伯語、泰語、印尼語、印地語等 40+ 語言。
- 多語言能力是文件能力摘要，不等於當前帳戶的每個 speech tier 或模型都已 entitlement；仍要讀回目前 Audio／TTS 選單。

## 10. 精準編輯

H3 可接受：

- 替換、增加或移除人物與物件。
- 更換背景、場景、天氣與光線。
- 增加視覺效果或調整材質。
- 替換對白、音效、音樂或音色。
- 同時修改多個變數，並要求未指定部分保持。

編輯提示詞要分成：

1. 保留清單。
2. 修改清單。
3. 新事件與時間線。
4. 負面限制。

對真實影片做 AR／世界編輯時，先鎖定原始相機、演員動作、幾何與光線，再描述新增的 AR 元素；否則模型可能重生成整個場景。

### 10.1 角色與物體編輯

以身份圖、物件圖或現有影片鎖定要保留的主體，再用替換／增加／移除與時間線描述修改；未指定的角色、姿勢、材質與構圖要列入保留清單。

### 10.2 場景與視覺效果編輯

可以改背景、天氣、光線、色彩、材質與特效。對 AR 或世界編輯，先鎖定相機、幾何、演員動作與原始光線，再加入指定元素。

### 10.3 聲音、台詞與音色修改

明確指定要替換的台詞、語言、音色、音效、音樂與混音關係；未指定的聲音保留。音色來源、對白文字與情緒不能只靠音訊檔名推測。

### 10.4 高精度的指令遵循

把長 prompt 拆成素材角色、核心創意、鏡頭／時間線、音效／對白與負面限制；使用具體可見事件，並在生成後逐項 QA，不把「模型理解」當作結果證據。

## 11. 商業場景

### 11.1 品牌與影視

適合預告、TVC 與品牌形象。重點是鏡頭結構、轉場、文字、聲音與品牌限制；文字可讀性要另行 QA。

### 11.2 視覺包裝

適合片頭、MV、社群內容與視覺實驗。把設計語言、可讀文字、節拍、切點與音樂設計一起描述。

### 11.3 Motion Graphics／MG／AE

精確限制設計系統、允許文字、版面與動畫。若模型把文字生成成亂碼，可把核准文字做成圖片，並明寫「將它理解為圖像而不是重新排字」。

### 11.4 AR 合成

保留真實素材的鏡頭、動作、場景與幾何，只在其上加入或替換指定世界元素。

### 11.5 AI 短劇

適合直式短劇、角色表演、對話與聲音。對每個角色、場景、表演、畫內／畫外說話與鏡頭切換做精準約束。

### 11.6 商品與電商

適合商品廣告、功能展示與轉換素材。商品外形、Logo、材質、顏色與功能不能被模型自行改寫。

### 11.7 數位產品、遊戲與 UI

可製作遊戲 UI、網站、產品互動與 HUD。用時間線說明點擊、滑動、狀態變化與回饋，並 QA 文字與互動邏輯。

### 11.8 硬體、工業與具身智能

保留機械手臂、機器人或產品的幾何與動作，再替換背景或光線；不能為了風格重生成機構。

### 11.9 動畫與風格化

適合遊戲 CG、角色 PV、動漫、黏土、中式 3D 與 FPS。優先鎖角色身份、畫風、鏡頭規則與連續性。

## 12. 常見失敗模式

| 問題 | 修正 |
| --- | --- |
| 一整段沒有結構 | 改成參考素材、核心創意、可見過程三段。 |
| 上傳素材但沒有角色 | 為每個素材標記身份、動作、場景、鏡頭、風格或聲音用途。 |
| 同時要求音樂與無 BGM | 選一個目標，移除矛盾。 |
| 一鏡到底又分多鏡 | 改為單一連續事件，移除 Shot 編號。 |
| 要求人臉一致但沒有身份圖 | 加入人物參考並標為身份來源。 |
| 無參考且文字太短 | 補外觀、場景、動作與風格。 |
| 對白塞不進鏡頭 | 縮短台詞或延長／重分鏡頭。 |
| 只說抽象感受 | 換成可見動作、光線、表情、材質與聲音。 |
| 只把音訊關掉但仍有嘴型 | 同時加入沉默狀態、無嘴型限制與持續非說話動作。 |

## 13. 實務觀察與不穩定項

本節來自官方文件頁面的使用者留言與官方回覆，不等同穩定產品保證：

- 不想要的字幕仍可能出現。
- 角色替換與長段身份一致性可能波動。
- 精確循環、無縫 loop、字幕移除與嘴型抑制可能需要多次迭代。
- 音樂與動作同步適合用事件順序與明確進出點描述，但不能把提示詞時間碼當成幀級保證。
- 新手點數、保留天數與方案規則可能依活動或版本改變；不得從舊留言推定目前帳戶權益。

把這些項目列為生成後 QA 與可能的一變數重試理由，不把它們寫成模型必然支援或必然失敗。
